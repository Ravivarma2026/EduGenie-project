# 🧠 EduGenie

### ✨ Learn Smarter. Ask Anything. Understand Everything.

**EduGenie** is an AI-powered learning assistant designed to make education more **interactive, personalized, and accessible**.

Instead of simply providing answers, EduGenie focuses on helping students **understand concepts, solve problems, revise topics, and learn at their own pace.**

## 🚀 What is EduGenie?

Learning shouldn't be limited to textbooks and classrooms.

**EduGenie acts as a personal AI learning companion** that helps students interact with educational content, ask questions, understand difficult topics, and improve their learning experience.

> 💡 **Ask. Understand. Practice. Improve.**

# ⚡ Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/EduGenie-project.git
```

## 2️⃣ Enter the Project

```bash
cd EduGenie-project
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Configure Environment Variables

Create a `.env` file:

```env
PORT=3000
MONGODB_URI=your_mongodb_connection
AI_API_KEY=your_api_key
```

⚠️ **Never upload your API keys or `.env` file to GitHub.**

## 5️⃣ Run the Project

```bash
npm start
```

## 6️⃣ Open EduGenie

```text
http://localhost:3000
```
